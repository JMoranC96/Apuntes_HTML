1. Estructura basica de una pagina HTML

Los elementos fundamentales de una pagina HTML clasica son:

  • HTML (`<html>`)
    • Elemento principal y raiz del documento HTML.
    • Todo el contenido del documento esta incluido en el.
  • HEAD (`<head>`)
    • Contiene la cabecera oculta y metadatos (como el titulo de la pestaña con `<title>`).
  • BODY (`<body>`)
    • Contiene todo lo visible de la pagina.
    • Permite atributos de estilo antiguo como `bgcolor` y `text`.

2. Etiquetas relacionadas con texto

Sirven para dar formato y organizar la lectura visual en la pantalla:

  • Titulares: Desde `<h1>` (el mas grande) hasta `<h6>` (el mas pequeño).
  • Parrafos: Se definen con la etiqueta `<p>`, admitiendo alineaciones con `align="center"` o `align="right"`.
  • Modificadores de estilo: `<i>` para cursiva y `<b>` para negrita.
  • Lineas divisorias: La etiqueta `<hr noshade>` crea una barra horizontal limpia sin sombras.

3. Imagenes y enlaces

Permiten enriquecer la web conectandola con recursos externos:

  • Imagenes: Se insertan con `<img src="archivo.jpg" width="300" height="200" alt="descripcion">`.
  • Enlaces externos: Se utiliza `<a href="url" target="_blank">Texto</a>` para abrirlos en una pestaña nueva. Ejemplo: Visitar web de apoyo.
  • Enlaces internos: Usan anclajes con almohadilla (`#seccion1`) para saltar dentro de la misma pagina.

4. Listas y vinetas

Herramientas clave para estructurar menus y contenidos ordenados:

  • Listas no ordenadas (`<ul>`): Muestran elementos con viñetas redondas por defecto.
  • Elementos de lista (`<li>`): Indican cada opcion dentro de la lista.
  • Anidacion de niveles: Se pueden meter listas dentro de elementos `<li>` para crear estructuras complejas en varios niveles (como cartas de restaurantes o menus desplegables).
